# 需求澄清会话记录模板

> 用途：**一次澄清会话一份**（落 `.creature/tasks/plm-cs-<主题>/intake.md`）。作用是把"问过的、答过的、还没确认的"显式化——
> 不写下来就会出现"同一问题问了三遍"（用户最反感的一类客服行为），也会让分析人不知道哪些是用户亲口说的、哪些是客服推断的。
