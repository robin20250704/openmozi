# 03 · 分批次迭代重构演进方案（核心）

> 原则：**每批次 = 一次心跳**（改动图 → diff → 真实路径走查 → 验收报告），可独立部署、可回滚；系统全程在线（plm-service 现有 12 页面/2 集成测试不回退）。
