## 一句话结论

现有 plm-app 已具备**元数据驱动、检索双后端（pgvector+ES+RRF）、电子签名哈希链、OpenProject 单向集成**四块现成基座；IPD 扩展的最大缺口集中在 **①统一评审服务（DCP/TR 双门制）、②Outbox+事件契约+对账（双系统集成）、③Charter/BizPlan/CBB/管道四类新业务对象、④治理角色与项目窗口期权限**。重构采取"expand-contract 迁移 + 双跑切换 + 每批真实路径走查"纪律，5 波 13 批交付。
